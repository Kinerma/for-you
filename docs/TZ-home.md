# Техническое задание: Обновлённая главная страница (HomeView)

## 1. Общая концепция и визуал
Переработать главный экран (`HomeView`) в формате **Bento-сетки** из полупрозрачных стеклянных карточек (`.ultraThinMaterial`, скругление `24pt`, тонкая светлая обводка).
- **Динамический акварельный фон:** мягкие размытые пятна на фоне плавно меняют оттенок (`animation(.easeInOut(duration: 1.2))`) в зависимости от текущего настроения партнёра (например: *радость* — персик/сакура, *усталость* — спокойная лаванда, *романтика* — пыльная роза, *спокойствие* — мятно-кремовый).
- **Без лишних элементов в шапке:** иконка замка и переключатель языков вынесены в Настройки — на главном экране их быть не должно.

## 2. Структура экрана (сверху вниз, в `ScrollView`)

### Блок 1: Чистая шапка (Header)
- **Динамическое приветствие** по времени суток с локализацией (`RU` / `繁體中文` / `EN`): *Доброе утро / Хорошего дня / Уютного вечера / Доброй ночи*.
- **Пилюля «Мы вместе»:** компактный бейдж под заголовком с автоматическим подсчётом дней от даты начала отношений (берётся из `rooms/{roomId}/meta.relationshipStartDate`), например: `Мы вместе: 142 дня`.

### Блок 2: Настроение и «Пульт заботы» (Mood Section)
Две стеклянные карточки рядом (`HStack`), а поверх стыка ровно по центру — круглая плавающая кнопка **«Обнять»**.

**Карточка «Моё настроение»:**
- Эмодзи статуса + короткий текст настроения.
- **Шкала «Заряда батарейки» (0–100%):** компактный градиентный индикатор/ползунок энергии (позволяет быстро обновить уровень сил).
- **Тег «Что мне сейчас нужно»:** один выбранный чип (например: *Обнимашки*, *Вкусняшку*, *Поболтать*, *Просто рядом*, *Тишины* — локализовано на 3 языка).
- По тапу на карточку открывается компактный `Sheet` для быстрой смены эмодзи, уровня энергии, текста и чипа.

**Карточка «Настроение партнёра»:**
- Отображает в реальном времени эмодзи, полоску батарейки, статус и тег потребности партнёра.
- **Импульс поддержки (по тапу):** нажатие на карточку отправляет партнёру «импульс заботы» — запускает локальную анимацию падающих лепестков сакуры/сердечек поверх экрана (`Canvas` / `TimelineView`), срабатывает мягкий тактильный отклик (`sensoryFeedback(.impact)`) и улетает push-уведомление партнёру.

**Центральная кнопка «Обнять» (между карточками):**
- Небольшая круглая градиентная кнопка с иконкой сердца.
- **Механика удержания (`LongPressGesture` ~1.5 сек):** пока палец удерживается, от кнопки по экрану расходятся акварельные круги-волны, а телефон выдаёт нарастающий ритм сердцебиения через `CoreHaptics`. По завершении удержания партнёру уходит push «Тебя обняли» (если оба открыли приложение одновременно — синхронная вибрация).

### Блок 3: Bento-ряд (2 квадратные карточки `1:1` рядом)

**Слева — Умный обратный отсчёт (Smart Countdown):**
- **Если есть ближайшее событие в календаре:** категория, название события, крупный счётчик оставшихся дней/часов и тонкий прогресс-бар. Тап открывает это событие в `CalendarView`.
- **Если событий пока нет (Empty State):** карточка автоматически трансформируется в приглашение *«Куда пойдём? Свайпнуть идеи»* — тап сразу открывает режим выбора из Копилки идей.

**Справа — Полароид / Рисунок дня (Daily Moment):**
- Слегка наклонённая (`rotationEffect(.degrees(2))`) карточка в стиле мини-полароида с белой рамкой.
- Отображает последнее фото или быстрый скетч пальцем от одного из партнёров, короткую подпись и кто/когда обновил.
- По тапу открывается `Sheet`, где можно либо выбрать фото (`PhotosPicker`), либо нарисовать новый мини-скетч пальцем (SwiftUI `Canvas` с 4–5 пастельными цветами и ластиком), добавить подпись и отправить.

### Блок 4: Широкая карточка «Вопрос дня» (Daily Quiz)
- Показывает категорию и превью ближайшего неотвеченного вопроса из `couple_quiz_questions.json` на текущем языке.
- **Индикатор активности партнёра:** если партнёр уже ответил на этот вопрос, карточка получает мягкую пульсирующую обводку и бейдж *«Уже есть ответ — твоя очередь»*.
- Тап переводит прямо на этот вопрос во вкладке `QuizView`.

## 3. Дополнения к схеме данных (Firebase Firestore)

```text
rooms/{roomId}
  ├── meta: {
  │     relationshipStartDate: Timestamp,
  │     partnerAName: String,
  │     partnerBName: String
  │   }
  ├── moods/{partnerId}: {
  │     emoji: String,
  │     moodType: String,       // "happy" | "tired" | "romantic" | "calm" (для цвета фона)
  │     statusText: String,
  │     energyLevel: Int,       // 0...100
  │     needTag: String,        // "hugs" | "treat" | "talk" | "quiet" | "together"
  │     updatedAt: Timestamp
  │   }
  ├── interactions/latest: {
  │     type: String,           // "hug" | "support_petals"
  │     fromPartnerId: String,
  │     createdAt: Timestamp
  │   }
  └── dailyMoment/current: {
        type: String,           // "photo" | "sketch"
        imageUrl: String,       // Firebase Storage URL (или сжатый base64 для скетча)
        caption: String,
        authorId: String,
        updatedAt: Timestamp
      }

# Техническое задание: iOS-приложение для пары (Couple Space)

## 1. Суть проекта
Личное нативное iOS-приложение для двоих (под распространение через TestFlight).
Главные задачи:
1. Узнавать друг друга лучше через интерактивный опрос с механикой взаимного открытия ответов.
2. Вести общий календарь планов/свиданий и общую «копилку идей» (wishlist).
3. Поддерживать три языка интерфейса с мгновенным переключением внутри приложения: традиционный китайский (繁體中文 — Макао/Гонконг), русский (RU) и английский (EN).

## 2. Технический стек
- **Платформа:** iOS 17.0+, только портретная ориентация.
- **UI:** SwiftUI, архитектура MVVM.
- **Синхронизация и БД:** Firebase Firestore (real-time синхронизация между двумя устройствами через общий `roomId`) + Firebase Cloud Messaging (push-уведомления о новых ответах и событиях).
- **Безопасность:** LocalAuthentication (Face ID) + 4-значный PIN-код в Keychain.
- **Нативные фишки:** Haptic Feedback (`sensoryFeedback`), задел под WidgetKit (виджет обратного отсчёта и настроения).

## 3. Дизайн-система (Нежная романтичная эстетика)
- **Фон:** светлый молочно-розовый (`#FDF7F8`) с мягкими размытыми акварельными пятнами-градиентами на фоне: пыльная сакура (`#F7D6E0`), пастельная лаванда (`#E5D9F2`) и тёплое шампанское (`#FCECDD`).
- **Карточки:** эффект матового жемчужного стекла (`.ultraThinMaterial` поверх полупрозрачного белого `Color.white.opacity(0.65)`), скругление `24pt`, тонкая светлая обводка `Color.white.opacity(0.6)`, мягкая цветная тень.
- **Акцентные кнопки:** градиент от пыльной розы (`#D988A1`) к мягкой лаванде (`#A890C4`), скругление капсулой (`Capsule()`).
- **Типографика:**
  - Заголовки: `.system(.title2, design: .serif)` (для `zh-Hant` — корректный fallback на `Songti TC` / `PingFang TC`).
  - Основной текст: `.system(.body, design: .rounded)` или стандартный SF Pro.
  - Цвет текста: вместо чисто чёрного использовать глубокий сливово-какаовый (`#4A3540`), вторичный текст — `#8A727E`.

## 4. Локализация (RU / 繁體中文 / EN)
- Реализовать `LocalizationManager` (`@Observable`) с сохранением выбранного языка в `UserDefaults`.
- Переключатель языка (`RU` / `繁中` / `EN`) должен быть доступен прямо из шапки/настроек и обновлять весь UI без перезапуска.
- Встроенные вопросы опроса должны хранить тексты сразу на всех трёх языках.

## 5. Структура экранов и функционал (MVP)

### Экран 0: Вход и защита (LockScreenView)
- При запуске (и по нажатию на иконку замка) открывается экран с матовым стеклом, 4-значным PIN-кодом (демо-код `1122`, с возможностью смены в настройках) и кнопкой входа по Face ID.
- При самом первом запуске — простой онбординг: выбор роли («Партнёр А» / «Партнёр Б»), ввод имени и вход в общую комнату по короткому коду (`roomId`).

### Вкладка 1: Главная (HomeView)
- **Шапка:** приветствие, переключатель языка, кнопка блокировки.
- **Карточка обратного отсчёта:** название ближайшего запланированного события из календаря и количество дней до него.
- **Виджет настроения (Mood):** два мини-блока (моё настроение и настроение партнёра) — выбор эмодзи и короткого статуса (синхронизируется в реальном времени).
- **Карточка «Вопрос дня»:** быстрый переход к неотвеченному вопросу из опроса.

### Вкладка 2: Опрос (QuizView)
- Сегментированный переключатель: «Вопросы» / «Наши ответы».
- **Механика карточек:** два формата — быстрый выбор «Или / Или» (2 большие кнопки) и открытый текстовый вопрос.
- **Механика Mutual Reveal (ключевая фишка):** пока текущий пользователь не ответил на вопрос, ответ партнёра скрыт под мягким блюром с подписью «Ответь, чтобы увидеть ответ партнёра». Сразу после отправки ответа блюр плавно снимается с тактильным откликом.
- **Категории вопросов:** «Комфорт и привычки», «Еда и свидания», «Мечты и вишлист».
- **Наши ответы:** хронологический архив всех пройденных вопросов с ответами обоих партнёров.

### Вкладка 3: Календарь и Копилка идей (CalendarView)
- **Месячная сетка календаря:** переключение месяцев, цветные точки под датами по категориям:
  - Еда / Кафе (`#E8998D`)
  - Прогулка (`#A3C4BC`)
  - Поездка (`#A890C4`)
  - Особый день (`#D988A1`)
- **Блок выбранного дня:** список планов на дату, кнопка «+ Добавить план» (название, время, категория, заметка).
- **Копилка идей (Wishlist):** расположена ниже на этом же экране. Список мест/фильмов/идей без привязки к дате. У каждой идеи есть кнопка «В календарь» — в одно касание переносит идею на выбранную сейчас дату.

### Настройки (SettingsSheet)
- Смена имени, выбор языка, смена PIN-кода, включение/выключение Face ID, код общей комнаты (`roomId`) для подключения второго iPhone.

  ├── meta: { createdAt, partnerAName, partnerBName }
  ├── moods/{partnerId}: { emoji, text, updatedAt }
  ├── quizAnswers/{questionId}: {
  │     category, type,
  │     answerA, answerB,
  │     updatedAt
  │   }
  ├── events/{eventId}: {
  │     title, date (YYYY-MM-DD), time,
  │     category, note, createdBy
  │   }
  └── ideas/{ideaId}: {
        title, category, note,
        createdBy, isScheduled
      }

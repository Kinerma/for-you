# Техническое задание: Интерактивные фичи и микро-взаимодействия (v2.0)

> **Контекст:** Этот документ является расширением базового iOS-приложения *Couple Space* (SwiftUI, iOS 17+, MVVM, Firebase Firestore/FCM, стиль Soft Pastel Glassmorphism, локализация `RU` / `繁體中文` / `EN`). Базовый функционал (вход, обычный календарь, базовый опрос) здесь не дублируется — описаны только новые интерактивные модули.

---

## Модуль 1. «Живая» связь и тактильность

### 1.1. Стикеры-рисунки на рабочий стол (Doodle Widget)
* **UX:** Мини-холст внутри приложения для быстрых рисунков пальцем, рукописных записок и пастельных стикеров. После нажатия «Отправить» рисунок сохраняется в облако и автоматически обновляется в виджете на рабочем столе партнёра.
* **iOS-реализация:**
  * Холст на базе `PencilKit` (`PKCanvasView`) или кастомный `SwiftUI Canvas` с ограниченной пастельной палитрой (пыльная роза, лаванда, сливовый, шампанское, белый) и 3 толщинами кисти + ластик.
  * Экспорт рисунка в PNG (сжатый до ~300–500px), загрузка в **Firebase Storage**, сохранение URL и timestamp в Firestore.
  * `WidgetKit` + **App Groups**: при получении silent push (FCM) или фоновом обновлении виджет скачивает последний рисунок и рендерит его в размерах `.systemSmall` и `.systemMedium`.
* **Firestore:**
  ```text
  rooms/{roomId}/doodles/latest: {
    imageUrl, senderId, caption, updatedAt
  }
  ```

### 1.2. «Обнять на расстоянии» (CoreHaptics + Real-time Presence)
* **UX:** Кнопка-кружок на главном экране. При долгом нажатии (`LongPress`) вокруг пальца расходятся мягкие акварельные волны, а партнёру улетает пуш *«Тебя обнимают прямо сейчас»*. Если оба партнёра удерживают кнопку одновременно, экраны подсвечиваются тёплым градиентом, а оба iPhone синхронно вибрируют в ритме спокойного сердцебиения.
* **iOS-реализация:**
  * `CoreHaptics` (`CHHapticEngine`) с кастомным паттерном двойного мягкого удара (ритм пульса: `intensity: 0.45 -> 0.7`, `sharpness: 0.25`).
  * Real-time отслеживание состояния `isHoldingA` / `isHoldingB` (лучше через Firebase Realtime Database или Firestore с автоматическим сбросом по таймеру 15 сек, если связь оборвалась).
* **Firestore:**
  ```text
  rooms/{roomId}/presence/hug: {
    partnerAHolding: Bool,
    partnerBHolding: Bool,
    lastTriggeredBy, updatedAt
  }
  ```

### 1.3. Эффекты настроения и «Отправить поддержку»
* **UX:** При выборе партнёром статусов вроде «Устала» или «Скучаю» фон его карточки мягко меняет оттенок, а у второго пользователя появляется быстрая кнопка «Отправить поддержку». Нажатие запускает на экране партнёра короткую анимацию падающих лепестков сакуры / сердечек с лёгкой тактильной отдачей.
* **iOS-реализация:**
  * Анимация частиц через `TimelineView` + `Canvas` (или `CAEmitterLayer`).
  * `sensoryFeedback(.impact(weight: .soft), trigger: ...)` при появлении эффекта.
* **Firestore:**
  ```text
  rooms/{roomId}/carePings/{pingId}: {
    type: "sakura" | "hearts" | "hug_sparkle",
    senderId, createdAt, seen: Bool
  }
  ```

## Модуль 2. Игровой выбор свиданий

### 2.1. «Тиндер» для идей из Копилки (Swipe Match)
* **UX:** Режим совместного выбора свидания. Карточки из существующей «Копилки идей» показываются стопкой. Свайп вправо — «Хочу сегодня», влево — «Не сейчас». Как только оба свайпнули одну и ту же карточку вправо, появляется экран **Match!** с анимацией конфетти и кнопкой «Добавить в календарь на сегодня / выбрать дату».
* **iOS-реализация:**
  * Стек карточек с `DragGesture`, плавным наклоном (`rotationEffect`) и индикаторами «Да / Позже».
  * Сессия голосования привязана к `sessionId` (можно перезапускать для нового вечера).
* **Firestore:**
  ```text
  rooms/{roomId}/swipeSessions/{sessionId}: {
    status: "active" | "matched",
    votesA: { [ideaId]: Bool },
    votesB: { [ideaId]: Bool },
    matchedIdeaId: String?,
    createdAt
  }
  ```

### 2.2. Колесо фортуны с тактильным щелчком
* **UX:** Альтернативный способ выбрать из 4–8 вариантов (подтягиваются из Копилки или вводятся вручную). При вращении колеса каждый проход стрелки через границу сектора сопровождается чётким механическим щелчком.
* **iOS-реализация:**
  * Отрисовка секторов через `Path` / `Canvas` в пастельной палитре.
  * Физика замедления (`withAnimation(.timingCurve(...))` или `CADisplayLink` для точного трекинга текущего сектора).
  * `UIImpactFeedbackGenerator(style: .light)` на каждое пересечение границы сектора и `.notification(.success)` на остановке.

### 2.3. Скретч-купоны желаний (Scratch Cards)
* **UX:** Галерея личных купонов, которые партнёры создают друг для друга (*«Свидание-сюрприз»*, *«Выбор фильма без споров»*, *«Любой бабл-ти за мой счёт»*). Новый купон приходит покрытым пастельным «защитным слоем» — его нужно стереть пальцем, чтобы увидеть сюрприз, а потом нажать «Использовать» (партнёру придёт пуш).
* **iOS-реализация:**
  * Поверх карточки с текстом купона лежит слой с маской (`.mask` с накоплением `Path` от `DragGesture` с `blendMode(.destinationOut)`).
  * Когда стёрто >55% площади, защитный слой плавно исчезает с тактильным откликом.
* **Firestore:**
  ```text
  rooms/{roomId}/coupons/{couponId}: {
    title, description, emoji,
    createdBy, recipientId,
    isScratched: Bool,
    isRedeemed: Bool,
    redeemedAt: Timestamp?
  }
  ```

## Модуль 3. Прокачка опроса

### 3.1. Режим «Насколько хорошо ты меня знаешь?» (Guess Mode)
* **UX:** Отдельная вкладка или еженедельный раунд в опросе. В каждом вопросе два шага: сначала пользователь отвечает **за себя**, затем **угадывает ответ партнёра**. После того как оба завершили раунд, открывается экран результатов с совпадениями и начисляются общие «звёздочки» (за них можно открывать новые пастельные темы/иконки приложения).
* **iOS-реализация:**
  * Поддержка альтернативных иконок приложения через `UIApplication.shared.setAlternateIconName(...)` как награда за накопленные звёздочки.
* **Firestore:**
  ```text
  rooms/{roomId}/guessRounds/{roundId}: {
    questionId,
    selfAnswerA, guessPartnerA,
    selfAnswerB, guessPartnerB,
    starsEarned: Int,
    completedAt
  }
  ```

### 3.2. Реакции и мини-комментарии в архиве ответов
* **UX:** В архиве «Наши ответы» под каждой карточкой можно поставить быструю эмодзи-реакцию (`🤍`, `🥹`, `😂`, `✨`, `🔥`) и оставить короткий комментарий-приписку, чтобы карточка превращалась в живой мини-диалог.
* **Firestore:**
  ```text
  rooms/{roomId}/quizAnswers/{questionId}/comments/{commentId}: {
    senderId, text, createdAt
  }
  // В самом документе quizAnswers/{questionId}:
  reactions: { partnerA: String?, partnerB: String? }
  ```

## Модуль 4. Воспоминания и «вау-эффект»

### 4.1. Полароиды с проявкой (жест встряхивания)
* **UX:** После прошедшего события в календаре (или в отдельной галерее) можно загрузить фото и короткую подпись. Для второго партнёра новый снимок появляется как размытый «непроявленный» полароид. Чтобы фото проявилось, нужно потрясти iPhone.
* **iOS-реализация:**
  * Отслеживание жеста встряхивания через `UIWindow.motionEnded(.motionShake)` или `CoreMotion` (`CMMotionManager`), чтобы проявка шла постепенно пропорционально силе встряхивания (`blur(radius: 25 -> 0)` + `saturation(0.2 -> 1.0)`).
  * Хранение сжатых фото в Firebase Storage.
* **Firestore:**
  ```text
  rooms/{roomId}/polaroids/{polaroidId}: {
    imageUrl, caption, eventId?,
    date, uploadedBy,
    developedByA: Bool,
    developedByB: Bool,
    createdAt
  }
  ```

### 4.2. Общая карта воспоминаний (Couple Map)
* **UX:** Интерактивная карта с нежными кастомными пинами всех мест, где вы побывали вместе (кафе, парки, поездки). При нажатии на пин открывается мини-карточка с датой, заметкой и прикреплёнными полароидами.
* **iOS-реализация:**
  * `MapKit` для SwiftUI (`Map`, `Annotation`, стиль `.standard(elevation: .flat)` с мягким оформлением пинов).
  * Поиск мест при добавлении через `MKLocalSearch`.
* **Firestore:**
  ```text
  rooms/{roomId}/places/{placeId}: {
    name, category,
    latitude: Double, longitude: Double,
    visitedDate, note,
    polaroidIds: [String],
    createdBy
  }
  ```

### 4.3. Капсула времени (Time Capsule)
* **UX:** Возможность написать письмо или записать короткое голосовое сообщение (до 60 сек) и «запечатать» его до конкретной даты в будущем (например, годовщина или через полгода). До наступления даты капсула отображается под замком с обратным отсчётом, а в день X прилетает пуш и её можно открыть.
* **iOS-реализация:**
  * Запись и воспроизведение аудио через `AVFoundation` (`AVAudioRecorder`, `AVAudioPlayer`) в формате `.m4a`, загрузка в Firebase Storage.
  * Проверка `unlockDate` с защитой на стороне Firestore Security Rules (не отдавать `text` / `audioUrl`, пока `request.time < resource.data.unlockDate`).
* **Firestore:**
  ```text
  rooms/{roomId}/capsules/{capsuleId}: {
    title, createdBy, recipientId,
    unlockDate: Timestamp,
    text: String?,
    audioUrl: String?,
    isOpened: Bool,
    createdAt
  }
  ```
